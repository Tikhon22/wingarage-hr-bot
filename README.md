# HR Telegram Bot — Инструкция по запуску

## Структура проекта

```
hr_bot/
├── bot.py              # Основной файл — логика диалога
├── states.py           # Состояния FSM (шаги диалога)
├── keyboards.py        # Кнопки (строятся из data/)
├── config.py           # Токен и ID чата HR
├── requirements.txt    # Зависимости Python
└── data/
    ├── vacancies.py    # ✏️  Вакансии — редактируйте здесь
    └── locations.py    # ✏️  Магазины/районы — редактируйте здесь
```

## Быстрый старт

### 1. Создайте бота в Telegram

1. Напишите [@BotFather](https://t.me/BotFather) команду `/newbot`
2. Следуйте инструкциям, получите **токен** вида `7123456789:AAF...`

### 2. Узнайте ID чата HR-специалиста

**Вариант А — личный чат:**
Напишите боту [@userinfobot](https://t.me/userinfobot) — он пришлёт ваш числовой ID.

**Вариант Б — группа/канал:**
1. Добавьте вашего бота в группу
2. Отправьте любое сообщение в группу
3. Откройте в браузере:
   `https://api.telegram.org/bot<ВАШ_ТОКЕН>/getUpdates`
4. Найдите `"chat": {"id": -100XXXXXXXXX}` — это и есть ID группы

### 3. Заполните config.py

```python
BOT_TOKEN = "7123456789:AAF..."   # ← вставьте свой токен
HR_CHAT_ID = 123456789            # ← вставьте ID (число)
```

Или задайте через переменные окружения:
```bash
export BOT_TOKEN="ваш_токен"
export HR_CHAT_ID="123456789"
```

### 4. Установите зависимости и запустите

```bash
pip install -r requirements.txt
python bot.py
```

## Как обновить список магазинов

Откройте `data/locations.py` и отредактируйте словари:

```python
MOSCOW_LOCATIONS: dict = {
    "msk_center": "Центр — ТЦ «Охотный ряд»",
    "msk_noviy":  "Новый магазин — ул. Примерная, 1",  # ← добавьте так
}
```

После сохранения файла **перезапустите бота** — изменения вступят в силу.

## Как обновить вакансии

Откройте `data/vacancies.py` и отредактируйте поля нужной вакансии:
- `name` — название (показывается на кнопке и в карточке)
- `duties` — обязанности
- `schedule` — график
- `salary` — зарплата
- `employment_type` — тип занятости
- `training` — обучение
- `registration` — оформление

## Деплой (продакшн)

### Railway.app (рекомендуется, ~$5/мес)
1. Зарегистрируйтесь на [railway.app](https://railway.app)
2. Создайте новый проект → Deploy from GitHub
3. Добавьте переменные окружения: `BOT_TOKEN`, `HR_CHAT_ID`
4. Готово — бот работает 24/7

### VPS (любой провайдер)
```bash

git clone ... && cd hr_bot
pip install -r requirements.txt

# Запуск через systemd или screen
screen -S hrbot

```

## Диалог бота (схема)

```
/start
  └─> Выбор вакансии (кнопки)
        └─> Карточка вакансии + выбор города
              └─> Список магазинов/районов
                    └─> Согласие на обработку данных
                          └─> Имя
                                └─> Телефон
                                      ├─> Сообщение HR-специалисту
                                      └─> Благодарность кандидату
```
